# Titanium.Net.Http

An HTTP client handler that always uses the managed TLS stack.

HTTP/1.1 and HTTP/2 go through an inner handler. Its connect callback opens the TCP socket and authenticates a `TlsStream`. The handler rewrites `https` to `http` and keeps port 443 so the inner handler does not open its own TLS stream. A caller http URI is sent as cleartext, including when it asks for version 3. A redirect is followed here, including an HTTP/3 response, and each hop is rewritten the same way, so an https Location stays on the managed stream. AllowAutoRedirect false returns that response. MaxAutomaticRedirections stops a longer chain, including an HTTP/3 chain. Authorization is dropped when the host changes, including on HTTP/3. The same host keeps it. A 300 or 302 turns POST into GET, including on HTTP/3. An HTTP/3 redirect to an http URL is fetched as HTTP/1.1. A later https hop returns to HTTP/3. Cancelling the request stops an HTTP/3 redirect while the next hop is waiting. A 303 turns POST into GET and leaves HEAD as HEAD, including on HTTP/3. A 307 keeps the method and body, and an HTTP/3 hop sends that body again. A cleartext hop sends it again too. A 301 turns POST into GET, including on HTTP/3. A 308 keeps the method and body, and an HTTP/3 hop sends that body again. A Cookie header is copied onto an HTTP/3 hop only when UseCookies is false. Cookies and decompression stay on the inner handler. A cleartext hop from HTTP/3 still decompresses gzip and sends a cookie stored for that http URI. A Set-Cookie on that hop is stored for the next request. `Host` stays the original host. An HTTP/3 redirect does not send a caller Host, and the next hop's `:authority` is the URI authority. The response's request is the caller's request, with the `https` URI.

The inner handler sends `:scheme http` on HTTP/2. There is no hook to change that. A `400` or `421` on a GET, HEAD, OPTIONS, or TRACE is retried once over HTTP/1.1 when the request allows a lower version. An exact HTTP/2 request that the server resets does not fall back to HTTP/1.1. A POST that allows a lower version is not retried after that reset. A server that selects HTTP/1.1 during ALPN is retried over HTTP/1.1 before any request bytes, for any method, when a lower version is allowed. A POST body is sent on that retry. An exact HTTP/2 request is not retried when ALPN selects HTTP/1.1. A request that starts at HTTP/1.1 and allows a higher version is retried, and the next request reuses that connection. Another port is remembered on its own and still tries a higher version. A certificate in SslOptions.ClientCertificates is presented when the server asks for one. LocalCertificateSelectionCallback chooses which certificate is presented. A certificate without a private key is skipped. SslOptions.TargetHost is the name sent on the handshake, including HTTP/3. The connection still goes to the URI host. QuicOptions.LocalEndPoint is the local UDP address of an HTTP/3 connection. When ConnectTimeout is infinite, QuicOptions.HandshakeTimeout stops a silent HTTP/3 handshake. EnabledSslProtocols that omit TLS 1.3 fail the request before it is sent. An empty SslOptions.TargetHost sends the URI host on an HTTP/3 handshake and on an HTTP/1.1 handshake. AutomaticDecompression gzip decodes an HTTPS HTTP/1.1 response. An HTTP/3 response with Content-Encoding gzip stays compressed. A direct HTTP/3 request leaves CookieContainer unchanged. An HTTPS HTTP/1.1 request sends a stored cookie, and a Set-Cookie on that response is stored. UseCookies false leaves that stored cookie off the request, and Set-Cookie stays out of the container. A Cookie header on a direct HTTP/3 request is sent. An HTTPS HTTP/1.1 request sends a caller Host. A direct HTTP/3 request uses the URI as :authority and leaves a caller Host off the request. A caller header is sent on HTTP/3. Connection, Upgrade, Keep-Alive, and Proxy-Connection are left off. An HTTPS HTTP/1.1 request sends a caller header. An HTTP/3 POST sends Content-Type with the body. An HTTPS HTTP/1.1 POST sends Content-Type with the body. An HTTP/3 request keeps the query on :path. An HTTPS HTTP/1.1 request keeps the query.

HTTP/3 opens a managed QUIC connection and reuses it for the same authority until 16 request streams, the idle timeout, or the connection lifetime. A further request opens another connection, up to `MaxConnectionsPerServer`. A GOAWAY on the peer's control stream stops new requests on that connection and closes it once nothing is in flight. The dynamic table is capped at 4096 bytes. A request inserts a field that is not in the static table when the peer allows a dynamic table and at least one blocked stream. A peer insert is decoded. The call returns after the response headers, and the body is read as the caller reads it. Cancelling that read stops it while it is waiting for the next frame. Cancelling an HTTP/1.1 body read stops it while the rest of the body is still waiting. Cancelling an HTTP/1.1 request stops it while the status line is still waiting. An HTTP/1.1 connection is reused until `PooledConnectionLifetime` elapses. The next request opens another connection. While that connection is busy, `MaxConnectionsPerServer` of 1 keeps the next HTTP/1.1 request waiting. An http request is sent to the configured proxy. The request line is the absolute URI. UseProxy false sends an http request to the origin even when a proxy is set. The request line is the origin path. Changing MaxConnectionsPerServer after the first request throws. An https request opens a CONNECT tunnel to that proxy, then the managed TLS handshake. A proxy that refuses the CONNECT tunnel fails the request before the TLS handshake. A HEADERS frame after the body is applied to the response trailers while that read runs. A DATA frame before those headers fails the request. A truncated HTTP/3 frame fails the request. An unknown HTTP/3 frame before the response headers is skipped. When `EnableAltSvc` is set, a later request that allows a higher version uses HTTP/3 after `Alt-Svc: h3` from the same origin. If that handshake fails before a request byte, the request continues on the adapter. The cache holds 256 origins. An entry ends when its `ma` elapses. A missing `ma` lasts 24 hours. `ma=0` and `clear` drop the entry. A different host is ignored.

`samples/HttpClientManagedStack` sends one HTTPS request as HTTP/1.1, one as HTTP/2, and one as HTTP/3:

```
dotnet run --project samples/HttpClientManagedStack -- https://example.com/
```

HTTP/1.1 must succeed for a zero exit code. HTTP/3 is still attempted, and the program reports a failure when that server does not accept QUIC.

The package is experimental. It is not a FIPS-validated module. While FIPS mode is on, `SendAsync` throws unless `AllowManagedStackUnderFips` is set or `TITANIUM_MANAGED_STACK_FIPS_OVERRIDE=1`.
