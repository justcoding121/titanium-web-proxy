## What has run

The in-process network corrupts a datagram and can black-hole every datagram after the handshake. `BytesArriveOnceAndInOrder` sends 256 bytes through delay, reordering, and duplication. `OneCorruptedDatagramIsNotDeliveredAsStreamData` flips one bit of one datagram. `ABlackholeDropsThePayload` sends 32 bytes into a network that drops everything. `AFlippedHandshakeDatagramDoesNotThrow` delivers a bit-flipped Initial and the handshake still completes. An empty datagram is not queued. A DATAGRAM frame closes the connection with protocol violation 0x0a and does not become stream data. Packet and frame seeds already refuse to throw. `MutatedDatagramsDoNotEscapeOrGrowWithoutBound` flips, truncates, inserts, and duplicates a client Initial and a STREAM frame. Nothing throws, and the received stream stays within the mutant. A flipped byte of a sealed stream datagram is discarded and the connection stays open. `AReboundAddressGetsTheReplyWithinTheAmplificationLimit` delivers a stream datagram from a new remote port. The reply uses that port, the path stays unvalidated, and the bytes sent stay within three times the bytes received. Key update is not implemented. A packet the current keys cannot open is discarded.
