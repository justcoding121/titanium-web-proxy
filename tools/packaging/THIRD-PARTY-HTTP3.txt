Host packages (NOT redistributed in this zip)
---------------------------------------------
Some Linux hosts also need system packages so MsQuic can load:

  Ubuntu/Debian: libnuma1 (and libmsquic when not using this RID zip)
  Alpine/musl:   numactl, lttng-ust (and libmsquic when not using this RID zip)

Install via `titanium http3-deps install` or your distro package manager.
Those libraries are LGPL/GPL and are intentionally not bundled here.

Pinned MsQuic / OpenSSL download URLs are recorded in
tools/packaging/http3-native.lock.json.
