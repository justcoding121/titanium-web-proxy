## Highlights

- **Linux OpenSSL leftovers:** when leftover `libssl.so*` / `libcrypto.so*` next to MsQuic cannot be deleted (often root-owned), the CLI exits with the exact `sudo rm -f` command and Inspector shows the same text in a dialog before MsQuic can abort.
- **Release gate:** `release-dry-run` builds, signs, and smokes Inspector, CLI, Plus, images, and Helm charts before a beta cut; product smoke gates publish.
- **Helm charts:** chart semver **1.0.8** tracks product **8.0.8** so OCI chart publishes do not overwrite **1.0.7**.
