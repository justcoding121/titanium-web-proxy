## Highlights

- **Fixed:** In-app and CLI updates under Decrypt HTTPS now reach the update feed (loopback MITM bypass for update traffic). 8.0.8 clients under Decrypt still cannot update in-app — turn Decrypt off once, or install the package from the GitHub Release manually.
- **Fixed:** Linux `deb` uninstall clears the loopback GNOME proxy for every desktop user (including headless CI and multi-user hosts).
- **Fixed:** Plus bundle apply prunes stale files left from older Plus zips; Homebrew formula shape passes `brew audit` for stable tags.
- **Fixed:** The Windows CLI updater copies each file, retries a locked file, writes `apply.log`, and records the installed version only after the overlay finishes.
- **Fixed:** A gateway Helm upgrade keeps a live `twp.yaml` instead of replacing it with the chart default.
- **Changed:** Inspector checks for updates on startup by default (Settings → uncheck “Check for updates on startup” to turn it off).
