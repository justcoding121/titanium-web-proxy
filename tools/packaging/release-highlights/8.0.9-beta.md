## Highlights

- **Known issue (8.0.8 clients):** Inspector and CLI 8.0.8 under Decrypt HTTPS fail the in-app update check (UntrustedRoot / feed network error) because the loopback MITM bypass is not in that build. Workaround: turn Decrypt off for the update, or install the package from the GitHub Release manually. Builds that include the `UpdateHttp` loopback bypass are not affected.
- **Lifecycle smoke:** upgrade, in-app apply, and uninstall coverage for Inspector, CLI, Plus, Helm charts, and images across shipped RIDs and package formats.
- **Release gates:** asset completeness and release-manifest verification; soft-to-hard `LIFECYCLE_ENFORCE` for new product-smoke steps.
