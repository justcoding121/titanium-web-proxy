## Highlights

- **Linux OpenSSL:** CLI and Inspector use the host OpenSSL. Leftover bundled `libssl.so*` / `libcrypto.so*` next to the app are removed on first start when writable; when they cannot be deleted (often root-owned), the CLI exits with the exact `sudo rm -f` command and Inspector shows the same text before MsQuic can abort.
- **Stale-if-error keep-alive:** a cached synthetic answer that closes only the origin socket keeps the client connection for the next request.
- **Reload readiness:** readiness is announced after the handler is registered.
- **Plus dashboard:** restyled with sticky header, Live / Connecting status, and a confirm step before drain.
- **Manager:** shutdown drain no longer races the in-flight request path.
- **Packaging:** musl launcher; macOS CLI zip binaries are fully signed and notarized; Helm chart archives are listed in `SHA256SUMS`.
- **Release gate:** `release-dry-run` builds, signs, and smokes Inspector, CLI, Plus, images, and Helm charts before a stable cut; product smoke gates publish.
- **Helm charts:** chart semver **1.0.8** tracks product **8.0.8** so OCI chart publishes do not overwrite **1.0.7**.
