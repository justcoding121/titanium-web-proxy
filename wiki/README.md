# Wiki sources

These Markdown files are the source for the project [GitHub Wiki](https://github.com/justcoding121/titanium-web-proxy/wiki).

The wiki is a separate Git repository. Changes under this directory are
automatically published by the `Sync GitHub Wiki` workflow after they are
pushed to the `develop` branch. This README contains source-maintenance
instructions and is excluded from the published wiki.

Page naming: a file named `Streaming-Bodies.md` is served at `/wiki/Streaming-Bodies`. `Home.md` is the wiki landing page.

**Do not** start a wiki page with `# Title` that matches the file name (hyphens → spaces). GitHub Wiki already shows that as the page heading; a matching H1 duplicates it in the body and TOC. Start with intro text, a `>` audience line, or `##`. Exception: `Home.md` may use `# Titanium Web Proxy` because that is not the page name.
