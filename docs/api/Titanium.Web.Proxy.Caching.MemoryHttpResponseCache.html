    Class MemoryHttpResponseCache

    In-process response cache bounded by bytes. Entries are charged for their body, headers and key; when the total would exceed MaxBytes the least recently used entries are evicted first. Zero cost when unused (not registered in middleware).

    Remarks

    The store is split into up to 16 independently locked shards, so concurrent lookups of different keys do not contend, and eviction recency is exact within a shard (approximate across shards). Each shard owns an equal slice of MaxBytes, and the shard count shrinks until every slice can hold one maximum-size entry. Resident bodies are exact-size arrays shared by all readers (a hit copies nothing); the pooled staging buffers used while a streamed body is accumulated are returned before the entry is stored.
