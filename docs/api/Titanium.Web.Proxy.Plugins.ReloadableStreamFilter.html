    Class ReloadableStreamFilter

    A script plugin seen as one Titanium.Web.Proxy.Abstractions.Scripting.IStreamScriptFilter of a passthrough listener. A listener keeps its filters for the life of the process, so this one asks current for the plugin of the configuration that is in force when a connection arrives, and pins that plugin to the connection: every later event of the connection goes to the same plugin, as its per-connection state lives there. Calls are counted against the owning PluginHost.
