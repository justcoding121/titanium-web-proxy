    ProxyLoopback

    Gets or sets whether loopback requests should use the proxy.

    Declaration
    public bool ProxyLoopback { get; set; }
    Property Value
    Type Description
    bool
    Remarks

    This adds the WinINET <-loopback> rule. It only affects applications that honor compatible Windows system proxy settings and can expose otherwise trusted local traffic to the proxy.
