    Class UdpRelayListener

    Relays UDP datagrams between clients and an upstream with one session per client endpoint. A single receive loop reads the listening socket; the first datagram from a client endpoint picks an upstream (a cluster destination through the load balancer, or the fixed forward host), connects a UDP socket to it, and later datagrams from that endpoint reuse the socket. Each session has its own upstream receive loop that sends replies back through the listening socket to that client endpoint only. Idle sessions are closed by a timer wheel, so no session owns a timer. The listener has no connection to any HTTP path.
