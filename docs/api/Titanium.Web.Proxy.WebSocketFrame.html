    Remarks

    Data is only valid for as long as the buffer it was decoded from is unchanged - it is a zero-copy slice of either the byte array passed into Decode(byte[], int, int) or the decoder's own internal reassembly buffer (used to hold onto a frame that arrived split across multiple calls), and both of those are reused/overwritten by later reads and later calls to Decode(byte[], int, int) on the same decoder instance. Consume Data (or call GetText()) while still enumerating the same Decode(...) call that produced this frame; copy it out (e.g. via Data.ToArray()) before retaining a WebSocketFrame for later use, otherwise its content can silently change or become garbage once more data flows through the decoder.

    The unmasked frame payload.
